Notes

This page reads public Roblox server information. Roblox's API does not provide browser access directly on all origins, so this starter page uses the public CORS relay at proxy.cors.dev. Do not enter your Roblox password, cookie, or other account credentials here.

The list is the first page returned by Roblox (up to 100 servers), then sorted by player count in this page. It may not include every server in a very large game. A server can fill up or close between refresh and join.

If the Join button does not open Roblox, use the normal Roblox app/browser and try again. Roblox may ask you to confirm opening the app.
